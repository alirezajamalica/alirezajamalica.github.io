# Ali Jamali — Personal Portfolio

Personal portfolio for healthcare data, SQL Server, reporting and IT support experience.

## Local development

Run npm install, then npm run dev.

## Updating content

Edit src/data/profile.json to update your profile, experience, projects, skills and contact links.

Replace public/resume.pdf with your updated PDF using the same filename to preserve the download link.

The AJ monogram is defined in HeroSection.tsx. Project cards can return to the original style by setting siteConfig.projectCardStyle to "classic".
